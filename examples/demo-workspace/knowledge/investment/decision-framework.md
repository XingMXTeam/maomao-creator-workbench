# 投资判断纪律（decision-framework）

> 内容来源：原 `knowledge/investment-judgment.md`（Phase 1），纳入投资分类。

**触发条件**：内容涉及投资 / 公司 / 财报 / 股票 / 基金 / 宏观 / 行业与钱相关话题时，本纪律自动生效，贯穿调研、观点、写作、审查与发布检查。

## 核心原则

1. **事实与观点分离**：每个判断标注是「事实」（有来源可查）还是「观点」（推理）。文字版中观点必须能看出来是观点。
2. **数据口径必查**：时间点、币种、单位、涨跌幅基准（年初至今 vs 过去一年）、财报期（如 FY2025 Q3）、汇率。
3. **信源分级**：
   - S 级：公司公告、交易所文件、SEC 文件、财报原文、监管公告
   - A 级：权威媒体（Reuters/Bloomberg/新华社/财新 等）、监管解读
   - B 级：主流财经媒体、券商研报（标注「研报观点」）
   - C 级：自媒体、社区帖子——只作线索，必须交叉验证后才能引用
4. **关键事实至少 S/A 级**。C 级来源的「事实」一律标注待核，不得直接写进成稿。

## 必做核查清单（写入 facts.md）

- 公司全名 + 股票代码 + 上市地
- 财报期与具体数字（营收/利润/现金/持仓，逐项注明来源页）
- 股价/涨跌的时间基准（「过去一年 +32%」要写清楚起止）
- 事件日期与背景（公告日、生效日）
- 引用的第二手解读是否与原文一致

## 禁止表述

- 「稳赚」「必涨」「保证收益」「跟我买」任何形式。
- 绝对化：「一定」「必然」「毫无风险」。
- 预测式荐股（「下季度必创新高」）；可以给条件式推演（「如果 X 持续，则 Y 可能…」）。

## 判断框架（观点输出用）

1. 为什么发生（驱动因素）
2. 影响谁（公司/行业/读者钱包）
3. 谁受益、谁受损
4. 持续性如何（一次性的还是结构性的）
5. 风险是什么（写清楚不确定性）

## 审查要点（Critic 使用）

- 是否区分「公司分析」与「股票判断」：分析质地 ≠ 建议买入。
- 是否虚构持仓 / 收益承诺。
- 判断是否有数据 + 推理链支撑。
- 投资类内容结尾必须包含提示，示例：
「以上仅为信息整理与个人观点，不构成投资建议。市场有风险，决策需独立判断。」
