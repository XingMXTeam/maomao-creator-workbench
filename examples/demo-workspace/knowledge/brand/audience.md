# 读者画像（audience）

> 内容来源：原 `knowledge/audience.md`（Phase 1），随 Phase 4 纳入 Brand 分类。

## 主力读者

25–40 岁，对理财 / 商业 / 个人成长感兴趣但非专业。刷小红书的目的：**用最少时间获得「能听懂的信息增量」**。他们不是来上课的，是来「刷到一条有用的」的。

## 他们为什么点开

1. **与我相关**：内容能接到「我的钱 / 我的工作 / 我的生活」（例：现金分红、房贷、工资、日常消费背后的公司）。
2. **反常识**：与直觉冲突的标题和开头（例：「伯克希尔突然开始买股票」）。
3. **数字具体**：具体数字比形容词可信（「3,250 亿美元」>「巨额现金」）。

## 他们为什么收藏

可执行的清单 / 表格 / 步骤 / 判断框架。收藏 = 内容「可带走」。

## 他们为什么评论

- 有立场可站（支持或反对一个判断）。
- 有疑问可问（术语、数据来源）。
- 有观点可反驳（反方视角留出的空间）。

## 语言偏好

- 中文口语，少术语；术语必解释。
- 不端、不装、不说教。
- 幽默适度，冷峻也可，但不要油腻。

## 对选题的启示

- 优先选「和读者钱包/职业/生活相关」的角度。
- 标题与开头先回答「关我什么事」。
- 结尾留下「可反驳的观点」，而不是「正确但无趣的总结」。
