# Research — 为什么 AI Coding Agent 越来越流行？

> 演示内容为虚构示意，仅用于展示 Workbench 流程与格式。

## 调研笔记

**背景**：AI Coding Agent（能自主拆解任务、读写代码、跑测试并迭代的 AI 编程代理）在过去一年从演示走向日常开发。

**三个驱动因素**：
1. 模型能力跃迁：长上下文 + 工具调用（tool calling）成熟，模型可以"看整个仓库再动手"。
2. 工具链成熟：沙箱执行、代码检索、测试反馈闭环打通，"Agent 写完→自动跑测试→拿报错继续改"成为标准回路。
3. 工作方式重构：从"人写代码、AI 补全"变成"人写需求、AI 写代码、人审代码"。

**反方证据**：
- 有观点认为 Agent 只擅长样板代码和已知模式，复杂系统仍依赖人类架构决策。
- 审计与责任问题：AI 生成的代码出 bug 谁负责，仍是悬而未决的问题。
