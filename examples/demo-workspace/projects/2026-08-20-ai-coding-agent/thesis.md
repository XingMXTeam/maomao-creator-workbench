# Thesis — 为什么 AI Coding Agent 越来越流行？

## 一句话主张

AI Coding Agent 流行不是"模型突然变聪明"，而是**长上下文 + 工具调用 + 测试闭环三件事同时成熟**，把编程从"人肉执行"变成了"人审机器执行"——门槛从"会写代码"变成"会提需求、会审代码"。

## 支撑证据

- 长上下文让 Agent 能看全仓库再动手（示意数据 1）。
- 工具调用让 Agent 能真正执行代码而非只出文本（示意数据 2）。
- 测试反馈闭环让"写错→改"可以自动迭代。

## 反方观点与回应

- 反方：复杂系统仍靠人类。回应：承认——但"大部分常规改动"已足够自动化，这正是流行的原因。
- 反方：责任归属未定。回应：这是普及速度的问题，不是会不会普及的问题。
