# investment-judgment：投资内容判断纪律

## 何时使用
内容涉及投资 / 公司 / 财报 / 股票 / 基金 / 宏观经济 / 行业与钱直接相关时，**自动生效**，贯穿阶段 1（调研）、3（观点）、4（写作）、6（发布检查）。

## 纪律

1. **事实与观点分离**：事实必须有来源；观点必须能被识别为观点（带「我认为/看起来/大概率」等标记）。
2. **数据口径**：每个数字注明时间点、币种、单位、基准（年初至今 vs 过去一年）、财报期。
3. **信源分级**：
   - S：公司公告 / SEC 文件 / 交易所 / 财报原文 / 监管
   - A：Reuters、Bloomberg、新华社、财新等权威媒体
   - B：主流财经媒体、券商研报（引用时标注「研报观点」）
   - C：自媒体/社区 → 只作线索，交叉验证后才能引用
4. **必做核查**（写入 facts.md）：公司全名+代码+上市地；财报期与数字；股价涨跌时间基准；事件日期；第二手解读与原文一致性。
5. **判断框架**：为什么发生 → 影响谁 → 谁受益/受损 → 持续性 → 风险。
6. **风险提示**：投资类成稿结尾必须有「非投资建议」提示；禁止「稳赚/必涨/跟我买」任何形式；禁止绝对化表述。
7. **交叉验证**：关键事实至少 S/A 级双源或单 S 源；C 级事实标注待核，不得入稿。

## 输出要求
- 调研时把信源分级记录到 `research.md`，核查结果记录到 `facts.md`。
- 在 thesis 与 publish 阶段输出观点时，显式走判断框架。
