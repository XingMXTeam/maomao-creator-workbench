# canva-carousel：Canva 图文页面结构

## 何时使用
用户说「做图文」「出图文结构」「排版」，或流水线进入阶段 5。

## 画布与基础
- 画布比例：3:4（小红书图文标准）。
- 输出的是**页面级结构**（每页文案 + 版式 + 视觉要点），不生成图片、不调用 Canva API。
- 输入：`projects/<最新项目>/draft.md`（或 thesis.md）+ `knowledge/brand/tone.md（另见 knowledge/writing/title-rules.md、structure-rules.md、ending-rules.md）`。

## 页面序列模板（8 页，可增减）

| 页 | 用途 | 元素 |
|---|---|---|
| P1 | 封面 | 主标题 ≤ 12 字 + 副标题（一句话承诺）+ 视觉钩子（数字/对比/悬念） |
| P2 | 问题页 | 抛出核心矛盾/问题，1 句大字 |
| P3 | 背景页 | 发生了什么：时间线 / 关键人物 / 数据背景 |
| P4–P6 | 干货页 | 每页一个要点：主结论 + 数据卡/对比表/图示 + 一句解释 |
| P7 | 反方页 | 反方观点 + 回应（体现判断质量） |
| P8 | 结尾页 | 金句/判断框架 + 行动号召 + 关注引导（自然） |

## 每页输出字段
- 页码与用途
- 文案：主标题 / 副标题 / 正文要点（每点 ≤ 20 字，数据具体）
- 版式：居中 / 上下 / 左右 / 卡片叠放；留白方向
- 视觉：主色与强调色（沿用品牌色系）、配图建议（实拍/图表/插画）、字体层级（大标题→小字注释）

## 输出要求
- 写入 `projects/<最新项目>/carousel.md`，用表格或列表呈现页面级结构。
- 每页的文案可直接复制进 Canva 文本框；注明哪些是装饰性文字、哪些是信息性文字。
- 检查：P1 封面 3 秒内能否看懂主题；信息页每页是否只讲一件事。
