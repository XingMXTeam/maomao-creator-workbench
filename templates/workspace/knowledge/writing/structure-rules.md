# 正文结构（structure-rules）

> 内容来源：原 `knowledge/brand-voice.md` 的结构模板 + Phase 4 推荐结构。

## 推荐结构（小红书文字版）

```
问题引入
   ↓
背景事实
   ↓
核心矛盾
   ↓
数据和案例
   ↓
我的判断
   ↓
投资者影响
```

## 落地模板（对应 Phase 1 模板）

1. **开头钩子**（1–2 句，点出矛盾或反常识）
2. **背景交代**（谁、发生了什么，≤ 3 句）
3. **核心分析**（2–4 段，每段一个要点，数据落地，术语带解释）
4. **反方视角**（1 段，体现判断质量）
5. **结尾**：判断框架 / 清单 + 开放问题

## 段落规则

- 每段一个要点；3–5 行一段，段间留白。
- 观点句必须有「我认为/看起来/大概率」等标记，不冒充事实。
- 每个关键数字紧跟来源或口径（时间点/单位/基准）。

## 判断四问（任何文章最后必须回答）

1. 这件事情本质是什么？
2. 为什么现在发生？
3. 对普通人/投资者有什么影响？
4. 我的判断是什么？

缺少任意一问 = 结构不完整，Critic 记为 FAIL。
